## Top five remaining risks

1. Native Windows/macOS and an actual freshly installed Hermes end-to-end session were not run. Upstream authoring/tool/tap evidence and local fixtures do not prove every runtime/backend configuration.
2. Live authenticated OpenAlex, Unpaywall without configured contact email, Semantic Scholar, supplementary repositories and paid services remain unverified in this pass. API prices, schema and quota can change after the recorded date.
3. GB/T 7714-2025 effective status is verified, but its complete adopted standard text was unavailable from the official public catalog. Full 2025 formatting must use an institution template/accessible standard; old examples are expressly 2015.
4. Nine input-dependent API-reference fragments are syntax-only, Excel engines/native fonts are not fully exercised, and the test version ranges exceed the single observed environment. The helpers preserve known limitations; they are not universal estimators.
5. Text overlap, topic matching, citation stance and bibliometric gaps remain heuristics with source coverage/identity/classification error. The skill explicitly prevents automatic plagiarism, saturation or absence conclusions.

The broad math-computation scope remains. Any domain taxonomy split is deferred to a separate successor after this correctness PR; no split is performed here. Optional future work should start from specific user tasks and measured routing failures, not a proliferation of skill names.
