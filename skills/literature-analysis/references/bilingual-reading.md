# 双语对照精读（Bilingual Reading）

对应工作流 J。跨语种快速消化论文的场景：分节要点翻译 + 术语表维护，不是全文翻译。默认目标语言为中文，用户可指定任意目标语言（英文论文译成中文、日文论文译成英文等）。

## 流程

1. 提全文：pymupdf 分页提文本，按章节切块（Abstract/Intro/Method/Results/Discussion/Conclusion）。
2. 逐节输出：
   - 目标语言要点 3~5 句（抓住该节回答了什么问题、结论是什么）
   - 关键句原文摘录 1~3 句（用户要核对术语或表述时直接看原文）
3. 术语表：全文统一译名，首次出现时记录"原文 → 目标语言译名"，后续沿用；不确定的译名标（待定）并给出常见译法。
4. 图表：不翻译，用一句话描述每张图/表说明了什么，指回原文位置。

## 输出格式

```
【第 3 节 方法】
要点:……
关键句: "……"(原文)
术语: self-attention → 自注意力; positional encoding → 位置编码

【图 2】(第 5 页)
说明:……（展示了模型在 XX 数据集上的准确率随层数的变化）
```

## 规则

- 技术含义不允许译偏：拿不准的句子给出直译加意译两版，标注让用户选。
- 公式不翻译、不重排，原样保留 LaTeX。
- 术语表随会话累积：同一主题多篇论文时复用既有译名表，保证一致性。
- 这是辅助阅读，不替代用户自己的判断；关键结论处提醒"建议核对原文第 X 段"。
